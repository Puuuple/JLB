# 🚀 Déployer sur Vercel (Déploiement automatique)

## Étape 1 : Créer un compte Vercel

1. Va sur **https://vercel.com**
2. Clique sur **"Sign Up"**
3. Choisis **"Continue with GitHub"** (important!)
4. Autorise Vercel à accéder à tes repositories

## Étape 2 : Importer le projet

1. Sur Vercel, clique sur **"Add New Project"**
2. Sélectionne le repository **"Puuuple/JLB"**
3. Dans **"Branch"**, choisis **"claude/production-oteQt"**
4. Clique sur **"Deploy"**

⏱️ Attends 30 secondes... et c'est en ligne!

## Étape 3 : Configurer le domaine (optionnel)

Tu auras une URL gratuite type : `jlb-cuisine.vercel.app`

Pour un domaine personnalisé (jlb-cuisine.fr) :
1. Va dans **Settings** → **Domains**
2. Ajoute ton domaine
3. Configure les DNS chez ton registrar

## ✨ Magie du déploiement automatique

**Maintenant, chaque fois que je fais des modifications :**

1. Je modifie le code
2. Je push sur GitHub (`claude/production-oteQt`)
3. Vercel détecte automatiquement le changement
4. Le site est redéployé en 30 secondes
5. **Tu recharges la page et hop, c'est mis à jour!**

## 📱 Lien de prévisualisation

Tu recevras aussi des **liens de preview** pour chaque modification, parfait pour tester avant de valider.

## 💰 Prix

- ✅ **Gratuit** pour sites statiques
- ✅ Bande passante illimitée
- ✅ Pas de limite de déploiements
