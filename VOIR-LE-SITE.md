# 📱 Comment voir votre site sur téléphone

## Option 1 : Netlify Drop (LE PLUS SIMPLE) ⭐

1. Sur votre téléphone, allez sur : **https://app.netlify.com/drop**
2. Si demandé, créez un compte gratuit (avec Google/GitHub/Email)
3. Téléchargez ces 3 fichiers sur votre téléphone :
   - index.html
   - Le dossier css/
   - Le dossier js/
4. Glissez-déposez les dans la zone sur Netlify
5. Vous obtiendrez un lien du type : `votre-site.netlify.app`

## Option 2 : GitHub Pages (depuis ordinateur)

1. Allez sur GitHub.com
2. Ouvrez votre repository `Puuuple/JLB`
3. Cliquez sur "Settings" (Paramètres)
4. Dans le menu de gauche, cliquez sur "Pages"
5. Sous "Source", sélectionnez la branche `claude/kitchen-bathroom-company-site-QYexj`
6. Cliquez sur "Save"
7. Après 2-3 minutes, votre site sera disponible sur : `https://puuuple.github.io/JLB/`

## Option 3 : Vercel (Rapide aussi)

1. Allez sur **https://vercel.com**
2. Créez un compte gratuit
3. Connectez votre compte GitHub
4. Importez le repository `Puuuple/JLB`
5. Déployez !

## 📥 Télécharger les fichiers pour Netlify Drop

Si vous voulez utiliser Netlify Drop, vous devez d'abord télécharger les fichiers depuis GitHub :

1. Allez sur : `https://github.com/Puuuple/JLB/tree/claude/kitchen-bathroom-company-site-QYexj`
2. Cliquez sur "Code" → "Download ZIP"
3. Décompressez et uploadez sur Netlify Drop

---

**Ma recommandation** : Utilisez l'option 2 (GitHub Pages) depuis un ordinateur, c'est gratuit et automatique une fois configuré !
