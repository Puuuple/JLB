# 📄 Alternative : GitHub Pages (100% Gratuit et Automatique)

## Configuration ultra-simple (5 minutes)

### Étape 1 : Activer GitHub Pages

1. Va sur **https://github.com/Puuuple/JLB**
2. Clique sur **Settings** (⚙️ en haut)
3. Dans le menu de gauche, clique sur **Pages**
4. Sous **"Source"**, sélectionne :
   - Branch : **`claude/production-oteQt`**
   - Folder : **`/ (root)`**
5. Clique sur **Save**

### Étape 2 : Attendre 2 minutes

GitHub va construire le site automatiquement.

### Étape 3 : Voir ton site

Ton site sera disponible sur :
```
https://puuuple.github.io/JLB/
```

## ✨ Déploiement automatique

Comme Vercel, **chaque fois que je push sur la branche**, GitHub Pages redéploie automatiquement le site en 1-2 minutes.

## 🌐 Domaine personnalisé (optionnel)

Pour utiliser ton propre domaine (jlb-cuisine.fr) :

1. Dans les **Settings** → **Pages**
2. Entre ton domaine dans **"Custom domain"**
3. Configure un CNAME chez ton registrar :
   ```
   CNAME: puuuple.github.io
   ```
